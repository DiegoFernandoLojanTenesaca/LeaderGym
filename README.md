# Leader Gym® - Figura Extrema

Landing page oficial de **Leader Gym®**, gimnasio ubicado en Loja, Ecuador.

## Tecnologias

- [Astro](https://astro.build/) v6 - Generador de sitios estaticos
- [Tailwind CSS](https://tailwindcss.com/) v4 - Framework de estilos
- Vanilla JavaScript - Animaciones y efectos interactivos

## Caracteristicas

- Diseno responsive (mobile-first)
- Animaciones de scroll (fade-in, parallax)
- Carrusel de servicios con navegacion tactil
- Video reels del equipo con control de audio
- Horario de clases interactivo
- Planes de membresia con comparador
- Contador regresivo de ofertas
- Integracion con WhatsApp Business
- Google Maps con ubicacion real
- Feed de Instagram
- Efecto typewriter en hero
- Hover 3D en tarjetas de membresia
- Contadores animados

## Desarrollo

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deploy

Desplegado en [Vercel](https://vercel.com) con integracion automatica desde GitHub.
